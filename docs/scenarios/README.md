# Текстовые сценарии

Тест-кейсы словами пользователя по готовым автотестам: для ручного прогона и для сверки с постановкой
тем, кто не читает код. Один файл — один `.feature`, путь повторяет `tests/features/`.
Слова — по [словарю](../user-guide/glossary.md). Пишет и сверяет с кодом навык Claude `scenario-text`.

| Текстовый сценарий | Автотест |
|---|---|
| [ui/booking.md](ui/booking.md) | `tests/features/ui/booking.feature` |
| [ui/map_labels.md](ui/map_labels.md) | `tests/features/ui/map_labels.feature` |
